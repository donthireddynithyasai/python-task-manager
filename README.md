# Python Task Manager

A simple command-line Task Manager application built using Python.

## Features

- Add tasks
- View tasks
- Delete tasks
- Input validation
- Error handling
- Unit tests

## Files

- `main.py` - Runs the Task Manager application
- `task_manager.py` - Contains task management functions
- `test_task_manager.py` - Contains unit tests

## How to Run

```bash
python main.py
How to Run Tests
python -m unittest
